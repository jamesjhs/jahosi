Keyboard shortcuts for Unity Editor

This guide is drawn from Unity's Unity shortcuts, Keyboard shortcuts, Manage keyboard shortcuts, and Scene view navigation documentation. Shortcut profiles, packages, custom tools and active Editor context can change bindings, so verify critical keys in the Unity Shortcuts window.

Transform tools

Q
View tool, used for panning and Scene view navigation.
W
Move tool in normal editing; forward movement in Flythrough mode.
E
Rotate tool in normal editing; move up in Flythrough mode.
R
Scale tool in the common default tool layout.
T
Rect tool in the common default tool layout.
V
Vertex snapping in the common default shortcut set.

Scene view navigation

Arrow keys
Move the Scene Camera like walking through the Scene.
Shift + Arrow
Move the Scene Camera faster.
Alt + LMB
Orbit around the current pivot in Perspective mode.
Alt + RMB
Zoom the Scene view on mouse setups that support it.
MMB drag
Pan with a three-button mouse.
`
Open the Overlays menu; use it to find View Options such as Scene Camera speed.

Flythrough and framing

RMB hold
Enter Flythrough-style navigation in Perspective mode.
W / S
Move forward or backward in Flythrough mode.
A / D
Move left or right in Flythrough mode.
Q / E
Move down or up in Flythrough mode.
Shift
Move faster while navigating.
F
Frame the selected GameObject in the Scene view.
Shift + F
Lock the view to the selected GameObject.

Shortcut management

Shortcuts window
Use it to view active bindings, assign shortcuts, remove or reset bindings, and manage profiles.
Profiles
Unity stores shortcut profiles outside the project, so your shortcuts can follow the Editor user rather than the project.
Conflicts
Unity can show shortcut conflicts when packages, tools or custom commands share a key combination.
Custom tools
Custom scripts and packages can add commands and shortcuts through Unity's shortcut-management APIs.

Plain-English glossary

Addressables

A package and workflow for loading assets by address, often used to manage downloadable content, memory pressure and content updates.

Animator Controller

An asset that defines animation states, transitions and parameters for characters, props or UI animation.

Asset

Any project file Unity can import or use, including models, textures, audio, scripts, materials, scenes and prefabs.

AssetBundle

A packaged group of assets that can be loaded at runtime, commonly used for downloadable or separately delivered content.

Bake

The process of precomputing data, such as lighting or navigation, so the game can reuse it efficiently at runtime.

Build Profile

A saved build configuration for a target platform, including settings that control how Unity produces the final player.

Canvas

The root element for Unity UI layouts. UI elements render inside a Canvas in screen space, world space or camera space.

Collider

A physics shape used for collision detection and triggers. It may be visible only through gizmos, not as rendered geometry.

Component

A modular part attached to a GameObject, such as Transform, Renderer, Collider or a custom script.

DOTS

Unity's Data-Oriented Technology Stack, designed around highly parallel, cache-friendly code for large or performance-heavy simulations.

ECS

Entity Component System, a data-oriented architecture where entities are identified by data and systems process that data.

Editor

The Unity application used to build scenes, import assets, configure projects, run Play Mode and prepare builds.

FixedUpdate

A scripting event called on the fixed physics timestep, usually the right place for physics-related Rigidbody changes.

Game View

The Editor view that shows what the active camera renders when the project runs.

GameObject

A core object in a Unity scene. Behaviour and data usually come from Components attached to it.

Gizmos

Editor-only visual aids that show invisible data such as colliders, lights, cameras, paths and custom debugging markers.

HDRP

The High Definition Render Pipeline, aimed at high-end visuals where platform and hardware budgets fit.

Inspector

The Editor panel used to view and edit the selected object's properties, components, assets and import settings.

Lightmap

A texture that stores baked lighting information so static lighting can render faster at runtime.

Material

An asset that defines how a surface is rendered, including shader choice, textures, colours and other surface properties.

Mesh

The vertex, edge and face data that describes a 3D object's shape.

MonoBehaviour

The base class most Unity scripts inherit from when they need common Unity event functions such as Start, Update or OnCollisionEnter.

NavMesh

Navigation data that describes where AI agents can walk, helping characters find paths around a scene.

Package Manager

The Editor window used to add, remove and update Unity packages, samples and dependencies for a project.

Play Mode

The Editor state that runs the project for testing. Changes made in Play Mode usually do not persist after stopping.

Prefab

A reusable GameObject asset that lets you create and update repeated object setups consistently.

Profiler

Unity tooling for measuring CPU, GPU, memory, rendering and other runtime performance so optimisation starts from evidence.

Project Settings

Central settings for input, physics, rendering, quality, player configuration, tags, layers and other project-wide behaviour.

Rigidbody

A physics component that lets an object respond to forces, gravity and collision movement through the physics engine.

Scene

A Unity asset that stores part of the project's world, UI, objects or setup.

Scene View

The Editor view used to inspect, select and arrange objects in the scene independently of the game camera.

ScriptableObject

A serialisable data container often used for shared settings, item definitions, configuration data or editor tooling.

Shader Graph

A node-based tool for creating shaders visually rather than writing shader code by hand.

Sprite

A 2D graphic asset used for characters, tiles, icons, UI and other flat visual elements.

Tag

A label assigned to GameObjects so scripts can identify broad object roles, such as Player or Enemy.

Terrain

Unity's built-in system for sculpting and painting large outdoor landscapes.

TextMeshPro

Unity's advanced text rendering package, commonly used for sharper UI and in-world text.

Timeline

A sequencing tool for arranging animation, audio, camera cuts and scripted events over time.

Transform

The component every GameObject has, storing position, rotation, scale and parent-child hierarchy information.

Trigger

A Collider mode that detects overlaps without physically blocking movement, often used for zones, pickups and interaction volumes.

UI Toolkit

Unity's retained-mode UI system for Editor extensions and runtime interfaces, based on visual elements and style sheets.

Unity Hub

The application used to manage Unity Editor installations, modules, licences and projects.

URP

The Universal Render Pipeline, often used when broad platform reach and scalable rendering matter.

Visual Scripting

Unity's graph-based scripting system for building logic with nodes instead of writing C# directly.
