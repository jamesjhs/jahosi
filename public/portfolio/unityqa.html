Project

UnityQA

Unity Engine tutorial Q&A · official-source guided · Node/Express + static UI + constrained AI workflow

UnityQA is a learning and navigation assistant for Unity users who know roughly what they want to build, but need help choosing the right official route through the Editor, scripting API, packages, render pipelines, components and project settings.

The problem is familiar: Unity has many valid ways to solve a task, and a learner can lose time copying a fragile shortcut from the wrong version, package or platform context. UnityQA gives a calmer answer: explain the concept, compare the likely routes, and point back to Unity documentation before the user commits to a workflow.

Core interaction

  1. 1. Ask a Unity workflow, Editor or scripting question
  2. 2. Attach official source context from a topic lookup
  3. 3. Get a plain-English explanation with trade-offs
  4. 4. Check Unity docs, package docs or vendor docs where needed

What it does

  • Explains Editor workflows, Scene view navigation, GameObjects, Components and Prefabs in approachable language.
  • Supports scripting, lifecycle, graphics, URP/HDRP, physics, animation, audio, UI Toolkit, navigation and profiler questions.
  • Provides topic-based official resource lookup with links and follow-up prompts.
  • Keeps confidential project, account, license and unreleased build details out of prompts through visible warnings.
  • Directs third-party Asset Store packages, platform SDKs and hardware drivers back to vendor documentation.

Technologies implemented

UnityQA is served from the Jahosi Node/Express application. The static page handles the interaction, local browser state and display controls; the server handles chat validation, source-guided prompt construction, resource lookup, rate limiting, Turnstile-aware sessions and OpenAI calls.
