Aviation Museum Archives and Gallery

A Node.js-powered image gallery hosting the archive photography collection for a local Aviation Museum. This was the biggest project yet of my journey into exploring the world AI-assisted coding, and before I'd particularly heard of Agentic AI - building on my coding skills and previous knowledge, I wanted to see how easy it was to parse out an exported database (from the museum software Modes, which used a custom Nexus-derived database), to make the content browseable in 21st-Century standards as opposed to the Windows 9x-esque interface of Modes.

After a lot of iterative steps, and purely using Google Gemini for help, the website (for internal use only, so far) has actually turned out to be very much a success!

Problem and goal

The archive material was valuable, but the exported collection was locked into an awkward legacy shape. The goal was to make photographs and metadata easier to browse, search and administer without asking volunteers to keep working through an outdated database interface.

Solution and progress

The project parses the export into a web gallery with image listing pages, lightbox-style viewing and back-end configuration. It is currently an internal-use success: the important step was proving that a difficult museum export could be made accessible through a normal browser.

Implementation

The implementation uses a Node.js web app, transformed archive data, server-side image handling and a small administrative back end. The development method was iterative: test a parsing approach, inspect the output, improve the browse experience, then add the controls needed to maintain the collection.
