Project

TLSCheckin

Very quick status checker · TypeScript + Express · SQLCipher · Turnstile · self-hosted

TLSCheckin is a deliberately small status checker. Its public flow is designed for moments where speed matters: enter a short check-in code, pass Turnstile when configured, and immediately record that you are OK while showing the latest status for the people you follow.

The project solves a practical problem around low-friction reassurance. It avoids building a noisy social network or heavy messaging product. Instead, it focuses on the minimum useful loop: private identities, quick check-ins, follower visibility, secret PIN links, optional acknowledgement SMS and an admin page for managing users and relationships.

Check-in flow

  1. 1. User submits today's date code plus their identity
  2. 2. Server verifies Turnstile and the local-time secret
  3. 3. Status, audit trail and session are updated
  4. 4. The landing page shows followed users and quick account options

Product stance

Focus

Fast, quiet, private

Storage

Encrypted local database with bcrypt-hashed passwords and PINs.

What it does

  • Records public check-ins using a date-based code or a generated secret link plus PIN.
  • Shows each user the latest status of approved followed users.
  • Supports friend requests, follower revocation, one-read personal messages and custom public-login passwords.
  • Stores SMS gateway credentials in the encrypted database and can send acknowledgement messages where configured.
  • Provides an admin interface for users, follow relationships, SMS presets, credentials, password changes and audit events.

Technologies implemented

TLSCheckin is a Node.js TypeScript application with Express 5, SQLCipher through `better-sqlite3-multiple-ciphers`, bcrypt, express-session, Cloudflare Turnstile verification, plain HTML/JavaScript pages, Docker/Compose files, Debian/PM2 deployment notes and a local-time rule for app-visible dates.
