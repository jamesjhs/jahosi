Project

Jahosi API

TypeScript API gateway · source-scoped AI products · SQLCipher admin storage · versioned JSON contracts

The Jahosi API project separates product backend logic from the public portfolio website. The problem it addresses is architectural: AI-assisted products like TeachMe, SocialQA, BlenderQA and splash! need shared server-side handling for prompts, source lists, reports, usage controls, OpenAI calls, secrets and future mobile entitlements.

Instead of letting every static page grow its own backend shape, this repo defines a reusable API foundation: JSON in, JSON out, clear product namespaces, testable prompt builders, source packs, admin settings, health checks and deployment notes for a separate `api.jahosi.co.uk` service.

API shape

  1. 1. Client calls a product route such as `/v1/teachme/chat`
  2. 2. Server validates request, product rules and source context
  3. 3. Provider calls stay behind the API boundary
  4. 4. Client receives a stable Jahosi response shape

Design goal

Boundary

Web app stays simple

Security

Secrets, source packs and provider calls remain server-side.

What it solves

  • Gives browser and future Android clients stable versioned API contracts.
  • Centralises OpenAI provider calls, prompt assembly, source validation and error envelopes.
  • Keeps product safety rules isolated so one assistant's source boundaries do not leak into another.
  • Provides health/readiness routes, request IDs, CORS controls and testable product modules.
  • Adds admin settings, encrypted local persistence and SMTP-aware operational plumbing.

Technologies implemented

The active implementation is a Node.js/TypeScript server with Express routes, Zod-style validation patterns, SQLCipher-backed settings/admin storage, OpenAI provider abstraction, product modules, tests, PM2 deployment notes and `.env`-driven configuration. The repository is currently not public, so there is no public GitHub link on this page.

Live status

This is primarily a backend service and migration foundation. The intended live host is `api.jahosi.co.uk`; public client-facing behaviour is exposed through the individual product pages as they migrate to the shared API.
