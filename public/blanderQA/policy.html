BlanderQA policy, use policy and disclaimer

How BlanderQA works, what it can and cannot do, how information is handled, and what users should check before relying on any answer.

Status of this policy

Version: 1.0.0. Published: 24 June 2026. Last updated: 24 June 2026. Sources reviewed: 24 June 2026.

This policy is written for BlanderQA at https://jahosi.co.uk/blanderQA/. It will be updated over time as Blender 4.x, the source list, and the hosting or AI setup change.

This page is not legal advice. It is a practical public statement of how the BlanderQA page is intended to work and the limits users should understand before using it.

Plain-English summary

  • BlanderQA is an experimental AI-assisted information page for Blender 4.0. It is not a substitute for the Blender manual or professional training.
  • Use it as a guide to compare workflows, find official resources and ask better questions.
  • Do not treat any answer as the only valid workflow. For many Blender tasks, several approaches can work.
  • Always check the official Blender 4.0 Reference Manual, release notes, API docs or Blender Foundation pages before relying on an answer.
  • Do not enter sensitive personal, financial or account details into the chat.
  • BlanderQA is instructed to stay within the official Blender 4.0 source list and to refuse unsupported speculation, unofficial shortcuts and version-mismatched advice.

What BlanderQA is

BlanderQA is a plain-English Q&A page for Blender 4.0 users. It is designed to help enthusiasts and artists understand common topics such as modeling, modifiers, shading, animation, rigging, rendering, compositing, geometry nodes, the interface and Python basics.

Design philosophy

The page is intentionally restrained. BlanderQA is built around source discipline, plain-language explanation and practical signposting. It should help users understand what to try next and how different workflows compare, not force a single way of doing things.

Functional overview

  • The chat sends the user's question and recent temporary browser-session chat history to the BlanderQA server.
  • The server passes the question to a configured AI service with instructions to use only the validated Blender 4.0 source list.
  • The page includes starter prompts, common questions, topic lookup by Blender area, display controls and browser-side PDF export.
  • Starter prompts and common questions move focus back to the chat panel, show status text, and reveal the generated answer where it appears.
  • The topic lookup sends a Blender subject to the BlanderQA server, which returns official manuals, release notes and other Blender Foundation resources.
  • After a successful topic lookup, limited official resource context may be sent with later chat questions so answers can point to the relevant Blender docs.
  • Cloudflare Turnstile may be used to reduce automated abuse before chat is enabled.

Use policy and disclaimer

Use BlanderQA of your own accord

By using BlanderQA, you choose to ask questions of your own accord. You remain responsible for deciding whether to act, what to check, and whether to cross-check the answer against the Blender manual or other official Blender sources. The page cannot know your project goals, scene setup, add-ons, render engine, hardware, version, or artistic intent.

Not a substitute for the manual

BlanderQA does not replace the Blender 4.0 Reference Manual, official release notes, API documentation or Blender Foundation announcements. It is a helper for explanation and navigation. If an answer conflicts with the official docs, the official docs win.

The chatbot instructions explicitly require it to prefer official Blender 4.0 resources, to identify version-specific behavior, and to note when more than one workflow may be valid. It should explain trade-offs rather than pretending there is only one correct method.

Workflow comparison

Many Blender tasks can be done several ways. BlanderQA should explain alternatives where appropriate, for example non-destructive modifiers versus direct mesh edits, nodes versus traditional settings, or baking versus live shading. If a user asks for a method, the bot may say something like, “have you considered doing it a different way, such as ...?” when that is genuinely helpful.

Limitation of advice

Do not rely on BlanderQA alone for production-critical decisions. A short answer can miss context such as object scale, topology, render engine, color management, animation intent or add-on behavior. Check the manual and test in your own file before committing to a workflow.

Safety and support

BlanderQA is not an emergency service and is not intended for crisis situations. If you encounter account, licensing or payment issues in Blender services, use official Blender Foundation support channels. If a question is about third-party assets, add-ons or services, verify the relevant vendor's own documentation and terms.

Privacy policy

Data controller and contact

The data controller for BlanderQA is James Rowson. For privacy questions, correction requests or communication preferences, use the Jahosi contact page.

Data you should not provide

Do not enter passwords, API keys, account details, personal documents, payment details, client files, private project links or any other sensitive information into the chat.

BlanderQA warns users not to enter sensitive information. It is not technically possible to stop every user from doing so, especially if they type sensitive information into free text. If the AI detects or appears to detect sensitive information, it is instructed to warn the user, avoid repeating the details, and provide only general guidance or ask the user to rephrase without sensitive information.

Information processed when using the page

  • Chat question: the text you submit is sent to the BlanderQA server and then to the configured AI service so an answer can be generated.
  • Recent chat history: recent messages are held in your browser session storage and sent with later questions to preserve short-term context.
  • Topic lookup context: after a successful topic lookup, the page may send returned official Blender resource links with later chat questions so the bot can give more targeted signposting.
  • Session token: a temporary browser-session token may be stored in session storage after Turnstile verification.
  • Display settings: high-contrast and large-font preferences may be stored in browser local storage.
  • PDF export: exports are generated in your browser from the conversation visible in that browser session.
  • Security and service data: standard web request metadata such as IP address, time, URL, user agent and error information may be processed by the server, hosting provider, rate limiter or security tools.
  • Turnstile: if enabled, Cloudflare Turnstile may process browser, device and interaction signals to check for abuse.
  • Third-party scripts: the page loads Cloudflare Turnstile and jsDelivr-hosted PDF export code. Those third-party services may receive ordinary browser request metadata such as IP address, user agent, requested URL and timing information.

Purpose of processing

Information is processed to provide the Q&A function, preserve temporary context in the user's browser session, generate topic signposting, reduce abuse, troubleshoot the service and improve safe operation. BlanderQA is not designed to build profiles, target advertising or sell user data.

Storage and retention

BlanderQA does not maintain a user account or permanent chat database for this page. The AI has no persistent memory of user inputs beyond the temporary session context needed to answer within the current browser session. Chat history is stored in browser session storage on the user's device for the current browser session. Display preferences are stored in local storage until cleared by the user. Server-side processing is request-based, although hosting, security, rate-limiting or upstream service logs may retain technical metadata according to their own operational settings.

Sharing with service providers

To operate the page, information may be processed by the hosting environment, the configured AI service, Blender Foundation reference pages used as official signposts, Cloudflare Turnstile if enabled, jsDelivr for the PDF export library, and the user's browser. External reference links open third-party sites; those sites have their own privacy policies and are not controlled by Jahosi.

User controls

  • Do not submit sensitive information.
  • Close the browser tab or clear browser session storage to remove local chat history for the current session.
  • Clear local storage to remove display preferences.
  • Use the browser's download/delete controls for any PDF export you create.
  • Use the Jahosi contact page for privacy questions, correction requests or communication preferences.

This policy is guided by UK data protection transparency principles, including the ICO's guidance that people should be informed about collection and use of personal data, purposes, retention and sharing.

Sources and freshness

BlanderQA is constrained to a curated source list of official Blender Foundation and Blender Project sources, including the Blender 4.0 Reference Manual, release notes, API docs and official support pages. The source list was last reviewed on 24 June 2026. Sources can change without notice. BlanderQA will be updated over time as able, but users must check the original source and test the workflow in their own file before acting.

Where BlanderQA cannot answer from the validated source list, it should say so and signpost the relevant official Blender source instead of inventing an answer.

Workflow and safety review

User perspective

  • The main risk is over-reliance: users may treat a clear AI answer as the only correct workflow.
  • The page now requires a disclaimer acknowledgement before asking the bot a question.
  • Starter and common-question buttons route users to the chat panel and reveal the answer area, reducing the risk that a generated answer appears away from the current viewport.
  • The page provides a return-to-chat control after a conversation has started and the user scrolls away from the chat area.
  • The page repeatedly tells users not to enter sensitive personal or account information. The bot also has instructions to warn users if sensitive information appears in a prompt, but it is not possible to guarantee prevention because users control what they type.
  • The AI has no persistent memory of inputs beyond temporary session context, but submitted text is still processed to generate answers and may be visible in technical or upstream processing flows.
  • The tool should remain careful, plain and source-linked, especially for version-specific behavior, nodes, modifiers, rendering and scripting questions.

QA inspector perspective

  • The server-side prompt constrains answers to a validated Blender 4.0 source list and requires references.
  • The server-side prompt explicitly requires refusals and warnings when the answer would depend on an unsupported version, an unofficial source, or speculation about how Blender works.
  • The source list includes official manuals, release notes, API documentation and Blender Foundation pages.
  • The topic lookup is a narrow signposting function, not a knowledge base or community forum replacement.
  • Local context passed to chat is limited to official Blender resource data returned by the lookup, and must not be used to infer unsupported features, hidden behavior or add-on quality.
  • PDF export is user-initiated and browser-side, but users should avoid exporting sensitive content.

Current compliance assessment

Source discipline: BlanderQA should stay within official Blender resources and should not present unofficial tutorials, forum guesses or outdated version behavior as authoritative.

Workflow guidance: The page should explain that multiple valid workflows may exist and should distinguish between preferences, trade-offs and hard constraints from the manual.

Privacy and data protection: The key risk is users entering sensitive personal or account data despite warnings. The current design mitigates this through warnings, browser-session storage, no account system, no permanent chat database for BlanderQA, and this privacy notice. A fuller legal review should confirm processor/controller roles for the AI provider, hosting provider and Turnstile if the project moves beyond prototype or experimental use.
